# Heisenberg

Heisenberg is a JavaFX desktop chatbot that keeps your tasks under control. Create to-dos, deadlines, and events; then find, sort, complete, or delete them through a compact chat interface.

## Run the app

Install Java 25, then run this command from the project folder:

```sh
./gradlew run
```
